## 2. Problem Statement (MISC — 01)

### Problem Description
Students completing Class 10 face one of the most critical decisions of their lives, yet often choose academic streams without adequate information regarding:
- Their true academic fit and aptitude strengths
- Long-term career progression and industry demand
- Family financial constraints and hidden total costs
- Multi-step alternative pathways (e.g., 10+2 vs. 3-Year Polytechnic Diploma)
- Scholarships, fee concessions, and education loan realities

Most conventional EdTech platforms act as simple marketing aggregators pushing a single college or coaching package.

## 4. Solution Overview

**PathPilot AI** does not tell a student "what to choose." Instead, it acts as an **interactive flight simulator** for educational and career trajectories:

1. Takes comprehensive student profile inputs (marks, strong subjects, aptitudes, budget, preferred location).
2. Generates **4 diverse, structured educational progression routes** rather than a single recommendation.
3. Provides a **5-Factor Decision Matrix** (Academic Fit, Interest Fit, Budget Fit, Admission Odds, Career Alignment) with interactive radar and bar visualizations.
4. Simulates live **What-If Scenarios** (e.g. 35% sudden budget drop, entrance exam score drops, hardware career pivots).
5. Provides **transparent institution comparisons** (Autonomous, Government Polytechnic, Private).
6. Calculates **Education Loan EMI and interest schedules** using standard reducing-balance formulas.
7. Features a **Dedicated AI Explanation Panel** powered by **Google Gemini 1.5 Flash** with **100% resilient deterministic local fallback**.

## 6. AI/ML Integration & Reliability Protocol

- **Model:** Google Gemini 1.5 Flash via Server-Side API (`/api/explain`).
- **Prompt Architecture:** Structured system prompt instructing the model to act as an objective academic counseling engine, returning typed JSON.
- **Security:** The Gemini API key is never exposed to the client browser and is strictly loaded from `.env.local` (git-ignored).
- **Deterministic Fallback:** If the API key is not configured, quota is exhausted, or the network times out, PathPilot AI seamlessly serves a deterministic local explanation generated by `lib/decisionEngine.ts`. **The demo never crashes.**

## 10. How to Install & Run Locally

### Prerequisites
- Node.js (v18 or higher; tested on v24.17.0)
- npm (v9 or higher; tested on v11.13.0)

### Steps

```bash
# 1. Clone repository
git clone <your-repo-link>
cd pathpilot-ai

# 2. Install dependencies
npm install

# 3. Configure Environment Variables (Optional - Fallback works out of the box!)
cp .env.local.example .env.local # or edit .env.local

# 4. Start local development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## 11. Environment Variable Setup

Create or edit `.env.local`:

```env
# Google Gemini API Key (from Google AI Studio: https://aistudio.google.com/)
GEMINI_API_KEY=your_gemini_api_key_here
```

> **Note:** If `GEMINI_API_KEY` is omitted, PathPilot AI continues to function flawlessly in **Deterministic Local AI Engine** mode.
